## 1. Overview & Pipeline Strategy

ISRO official examination PDFs are typically **bilingual**: questions are presented in both **Hindi** (Devanagari script) and **English** (either in side-by-side columns or stacked vertically).

### Ingestion Requirements:
1. **Language Filtering**: **Completely discard all Hindi text**. Extract **ONLY** the English question text and English option choices.
2. **Mathematical Precision**: Convert all mathematical notations, sets, grammars, expressions, and exponents into clean **MathJax LaTeX** format (`$ ... $` for inline math and `$$ ... $$` for standalone equations).
3. **Diagram Handling**:
   - Run the provided PyMuPDF extraction script to dump all PDF figures into `public/question-images/external/isro/`.
   - Embed figures in the question HTML using standard tags: `<br><br><img src="/question-images/external/isro/isro_<year>_q<num>.webp" alt="Figure for Question <num>" />` (optimized via `scripts/external-pipeline/optimize-all-external-images.mjs`).
4. **Taxonomy & Scoring**: Classify into canonical GateQA subject slugs (`algorithms`, `toc`, `compiler`, `os`, `dbms`, `cn`, `coa`, `digital-logic`, `discrete-math`, `engg-math`, `general-aptitude`). Standard ISRO scoring is `marks: 3`, `negativeMarks: 1`.

## 3. How to Extract All Images from the PDF

A turnkey Python tool using `PyMuPDF` (`fitz`) is pre-installed in this repository at [extract_pdf_images.py](file:///c:/Users/himanshu/Desktop/GATE_QA/scripts/external-pipeline/extract_pdf_images.py).

Run this command in your terminal:

```powershell
python scripts/external-pipeline/extract_pdf_images.py "path/to/your/isro_paper.pdf" --year 2024
```

### What this script does:
1. Opens the PDF and locates all embedded figures/diagrams.
2. Automatically filters out small watermarks, logos, and artifacts.
3. Saves high-resolution PNGs directly to `public/question-images/external/isro/isro_2024_p<page>_img<idx>.png`.
4. Outputs a JSON manifest (`public/question-images/external/isro/extracted_manifest_2024.json`) mapping each extracted image to its PDF page number.
5. You can easily rename or symlink any image to match the question number (e.g. `isro_2024_q12.png`).

## 5. Mathematical Explanation for Demo Question 57

For verification and sanity checking:
- **Given Grammar**:
  $$S \to aSb \mid T$$
  $$T \to bT \mid b$$
- **Step 1: Production of Non-terminal $T$**:
  $T$ produces one or more $b$'s: $T \implies b$, $T \implies bb$, $T \implies b^k$ where $k \ge 1$.
- **Step 2: Production of Non-terminal $S$**:
  $S$ produces $a^m T b^m$ for any $m \ge 0$.
- **Step 3: Combining $S$ and $T$**:
  Strings have the form $a^m (b^k) b^m = a^m b^{m+k}$ where $m \ge 0$ and $k \ge 1$.
- **Step 4: Defining Exponents**:
  Let $n = m + k$. Since $k \ge 1$, we have $n > m$ (equivalently $m < n$).
  Since $m$ can be $0$ (if $S \to T$ is chosen immediately, producing $b^k$), $m \ge 0$.
  Therefore, the language generated is:
  $$\{a^m b^n : 0 \le m < n\}$$
- **Conclusion**: Matches **Option (a)**. Answer is **A**.
